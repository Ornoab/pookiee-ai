POOKIEE V1.0 — QUICK START

1. Extract this ZIP.
2. Host the folder on an HTTPS static host (for example GitHub Pages). Microphone and install support require HTTPS or localhost.
3. Open the hosted site in Chrome on Android and Windows.
4. Open Settings > Google AI Studio link > create an API key > paste it > Save settings.
5. Start chatting. Voice input uses browser speech recognition; choose Bangla or English before tapping the microphone.
6. Install: Android Chrome menu > Install app / Add to Home screen. Desktop Chrome/Edge: install icon or browser menu.

IMPORTANT SECURITY
This beginner prototype stores the API key in this browser's local storage and sends requests directly to Google's Gemini API. Use only on your own devices; do not publish it as a shared public service or use on a shared device. Never share the API key. Google model availability and free-tier limits can change. Check Google AI Studio and official pricing/docs. Free-tier data handling may differ from paid tiers; review Google's current terms before use.

This is a first prototype: voice input/output uses browser speech features; always-on wake word, full device control, and cross-device synced memory are not included yet.
